# bg フォルダ（キャラ画像）

超数秘術本体アプリと同じフォルダ・命名規則です。ここに `{太陽数}.{キャラ名}.png`
（例：`1.軍師.png`、`17.闘士.png`、`33.召喚士.png`）を置くと、

- **RPGシート（index.html）** の禁書スタイルでは背景に薄く乗算合成で浮かびます
- **公式ギルドカード（guildcard.html）** では右面にそのまま差し込まれます

- **白背景のままでOK**。乗算合成で白は和紙に溶け、墨や朱の色はそのまま残ります
- 画像が無い番号は、ギルドカードではキャラ名の縦書き透かし、RPGシートでは純粋な和紙になります。33枚揃える義務はありません
- 作る順番は1番からではなく、実際のギルドメンバーの太陽数から
