# 盤面貼り付け書式（二段方式の接続仕様）

計算は本体アプリ（apps/hontai.html）が行い、結果をこの書式のテキストで
AI（関所・先生）に貼る。**AIに名前から計算させることは絶対禁止**（必ず間違えるため）。

本体アプリの「⎘ AI用コピー」ボタン（`copyBanmenForAI()` / `buildBanmenText()`）が
この書式を出力する。書式を変える場合は本体のコードとこの文書を同時に更新すること。

## 書式

```
【超数秘術 盤面】(アプリ計算結果)
■ 11の星
冥王星: <数> <キャラ名>
天王星: ...
海王星: / 土星: / 木星: / 火星: / 太陽: / 金星: / 水星: / 月: / 地球:
■ 11の扉
ASC: / DSC: / MC: / IC: / バーテックス: / アンチバーテックス: /
ドラゴンヘッド: / ドラゴンテイル: / キロン: / リリス: / SM:
■ 11の秘密
秘密1: / 秘密2: / 秘密3: / 秘密4: /
セレス: / ジュノー: / パラス: / ベスタ: / 肉体: / 精神: / 魂:
```

計33行。数は1〜33、キャラ名は正典の33キャラクター。

## AI側の受け取り規則

- 先頭が「【超数秘術 盤面】」で始まるテキストをアプリの正規の計算結果とみなす
- 33席に満たない部分貼り付け（太陽と月だけ等）も受け付けるが、
  その旨を認識して扱う
- 書式が崩れていても数字とキャラ名の対応が読めれば使ってよい。
  ただし**欠けている席をAIが推測・補完してはならない**
