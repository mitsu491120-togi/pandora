# 超数秘術 思想篇 — 対話からの整理

設計書（super-numerology-canon.md）が体系の仕様を定めるのに対し、
本書はその背後の思想を記録する。2026年7月の対話より。

## 1. 計算式は思想の写しである

体系の計算方法そのものが意味を運んでいる。後付けの解釈ではなく、
式の設計と思想が同型になっている。

- **魂 ＝ 5（ど真ん中）との距離。5は5のまま残る。**
  生きる軸は外に探すものではなく、既に中心に在る。中心に居ること自体は
  消えない価値として式に残る。自分探しの終わり＝「自分はここに居たと気付く」。
- **精神 ＝ 10（枠の限界）との距離。**
  精神とは常に限界との距離である。土星（限界）を受け入れない精神は
  視座が狭まり驕慢になる。受け入れがたいものへの許容が土星の受容。
- **肉体 ＝ 鏡写しの対の差分。**
  月は腑に落とすための鏡。鏡に没入すれば振り回される。

## 2. 太陽・月・地球の順序

- **月は自分では光らない。** 月光はすべて太陽光の反射である。
  月が操縦席にいる状態とは、鏡が自分をランプだと思い込んでいる状態。
  光は本物だが、光源の場所を取り違えている。
- **月は消すものではなく、共にあるもの。** 鏡を割っても光源は困らないが、
  夜に光を届ける経路が失われる。月は太陽の補佐として同化する。
  追放ではなく配置転換——太陽が操縦席、月は副操縦士。
- **主従の逆転は故障ではなく、未完了の段階。**
  子ども時代は誰でも月（欠乏欲求）が操縦席であり、それは発達の順序として正しい。
  欠乏が深いまま残ると月が席を譲れない。必要なのは月を安心させて
  席を譲れるようにすること。
- **順序の定式**: 太陽が発し、月が映し、地球が受ける。
  この順序が保たれていることを、人は創造的と呼ぶ。

## 3. 二つの根

- 物理的な根（チャクラの梯子の下端）は地球＝第1チャクラ。
- 存在論的な根はハート＝太陽。**ハートが根で、からだは受信機・媒体。**
- 土に張る根と、樹全体が畳み込まれていた種は別のものである。
- 計算上も地球（K20_mid）は太陽と月の両成分を受信して合成される数であり、
  からだは源ではなく、太陽の光と月の反射が合流して現実になる受信面。

## 4. 視差の原理 — 伝統はなぜ対で残るのか

- 旧約と新約、古典占星術と現代占星術、カバラと占星術——
  「どちらが正しいか」という問いはナンセンスであり、
  **合わせてみないと読み解けない構造**になっている。
- 目が二つあるのは、一つでは奥行きが見えないから。左右の像の食い違い（視差）こそが
  深さの情報である。像を一致させれば世界は平面になる。
- 実例: 柱の性別の問題は、カバラ単独でも占星術単独でも決着しない。
  両方を同時に持って初めて「性は交差して入れ子になっている」という
  第三の構造が見える。
- 分離が意図的な設計だったか必然だったかは決められないが、機能としては同じ。
  一つの視点に畳める真理なら、二つの伝統が両方生き残る理由がない。
  淘汰が「対でしか読めない構造」を選び出す。
- 体系上の対応: 第6チャクラ（サードアイ）は天王星と海王星の相席。
  二つの半球の食い違いが統合される場所が第三の眼である。

## 5. 戦争について

- 敵と味方という見方は、視差を「矛盾」として処理した状態である。
  相手の像との食い違いを深さの情報として統合すれば立体が見え、
  誤りとして排除すれば戦いになる。
- 片方の柱に立って向かいの柱を撃っている状態。二本の柱は同じ樹の枝であり、
  樹には敵も味方もない。
- 月に没入した状態（メタで見れない・感情に振り回される）の集団版が戦争である。
- 「敵も味方もない」は到達して保持する境地ではなく、月にはまるたびに
  何度でも思い出し直す過程である。SMが月の補数として毎回計算し直されるように、
  統合は状態ではなく登り直しである。

## 6. ハードとソフト、座と階段（再掲・思想面）

- 33ステータス（ハード）は名前から確定する。人生の可変部分は配線＝
  どの星をどの順で通るか（ソフト・パス）にある。
  決定論と自由意志の切り分けは、ハードとソフトの境界線でなされている。
- 身体でも同じ: 整数チャクラの星は「座」、.5の星（水星・金星・火星）は「階段」。
  人が生きるのは座ではなく階段であり、統合は状態ではなく過程である。
