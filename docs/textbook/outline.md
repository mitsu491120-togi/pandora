# 超数秘術 教科書 — 構成案

## 目的（これだけがものさし）

**超数秘術の世界観を共有して話せる人を増やす。**

- 読者に必要なのは、成り立ちの理屈ではなく「この見方で人と人生を語れること」
- 必要最低限でわかることが、詳しく知っていることに勝る
- ロジック・計算・カバラの歴史・出典の議論は本文に入れない
  （深掘りしたい人のための付録に隔離する）
- 各章の合格基準: 読んだ人がその章の言葉を使って、自分や身近な人のことを
  一つ語れるようになること

## 構成

### 序章 — この見方で世界を見ると
人はそれぞれ「キャラクター」を持って生まれてくる。33人いる。
名前だけでわかる。難しい理屈は置いてきた、という宣言。

### 第1章 — 太陽: あなたというキャラクター
自分の太陽キャラを知る。33キャラの一覧と、自分のキャラの読み方。
「らしく生きる」とはキャラに合った生き方のこと。

### 第2章 — 月: あなたの機嫌と本音
月は感情と本音。満たされないと同じところを回り続ける。
操縦席の話: 太陽が運転、月は助手席。逆転すると振り回される。
月を追い出すのではなく、安心させて隣に座ってもらう。

### 第3章 — まわりの人を見る
家族・友人・同僚のキャラを見てみる。
「あの人はああいうキャラ」とわかると、腹が立たなくなる。
変わらない人は変わらない。それでいい、という話。

### 第4章 — 人生の地図（11の星）
太陽と月のほかに9つの場所がある。ざっくり一言ずつ。
土星＝関所（しんどい時期は関所を通っている）、
冥王星＝導き（ふと来るメッセージ）など、使える言葉として渡す。

### 第5章 — 日々の使い方
執着は薄れて落ちるもの。天気のように人生は移ろう。
ダメな時もいい時もあるのを受け入れて、楽観的に生きる。
この体系の言葉で日常を語る例文集。

### 付録（読まなくていい）
- 計算のしくみ（知りたい人だけ）
- 生命の樹との対応（知りたい人だけ）
- 用語集

## 書き方のルール

- 一章は短く。読み切れる長さ（目安: 数分）
- 専門用語は使わない。使うなら最初に日常の言葉で言い換える
- セフィラ・カバラ・魔方陣・飛泊などの語は本文に出さない
- 例え話は設計者の言葉を使う: 操縦席、鏡、関所、天気、座と階段
- 「なぜそうなるのか」ではなく「こう見るとこう見える」で書く
- 各章末に「やってみる」を一つ（身近な人をこの言葉で一人語ってみる、など）
