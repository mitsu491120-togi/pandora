# 墨絵フォルダ（禁書ギルドカードの背景）

ここに `1.png` 〜 `33.png` を置くと、禁書スタイルのギルドカード全面に、
その人の太陽数に対応する墨絵がフルブリードで薄く浮かび上がります。

- ファイル名は太陽数そのまま：`1.png`（軍師）〜 `33.png`（召喚士）
- **白背景のままでOK**。乗算合成で白は和紙に溶け、墨だけが残ります（透過PNG不要）
- **朱などの色アクセントはそのまま残ります**。カードの深紅と調和する朱の差し色は有効
- 縦長（2:3程度）推奨。カード全面に cover 配置されるため、四辺は少し切れます。
  主要モチーフは中央〜上寄りに置くと顔が出ます
- 画像が無い番号は何も表示されず、純粋な和紙のままです。33枚揃える義務はありません
- 作る順番は1番からではなく、実際のギルドメンバーの太陽数から
